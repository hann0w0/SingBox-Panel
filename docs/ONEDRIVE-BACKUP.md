# 面板内 OneDrive 数据备份

设置页的 `OneDrive 云端同步` 只同步面板现有的数据备份归档。归档内容是
SQLite 快照、`jwt_secret` 和恢复清单；项目目录、面板二进制、Agent 文件和运行进程都不会上传。

## 授权

面板不要求填写 Client ID，也不要求用户注册 Microsoft Entra 应用。点击设置页的
`连接 OneDrive` 后，按页面提示完成微软设备码授权即可。

授权使用 OneDrive Client for Linux 的公开客户端配置，以便在服务器上直接完成设备码登录。
该客户端 ID 不是密码，面板不会保存微软密码；微软授权页可能显示该公共客户端的应用名称。
如果将来需要使用项目自己的授权身份，可以再替换为项目自有的免费 Microsoft 应用注册。

## 同步行为

- 授权成功后，OneDrive 根目录会自动创建 `singbox-panel-backups` 文件夹。
- `立即同步` 和自动任务都上传固定文件名 `singbox-panel-backup.tar.gz`。
- 自动同步周期固定为每 1 小时，新的备份使用 `replace` 覆盖上一份，不会按时间累积文件。
- 设置页可以下载或删除当前云端备份；删除后不会影响本机备份。
- 打开自动同步开关后，面板进程每分钟检查一次，到期后执行同步。
- OAuth 刷新令牌使用面板的 `jwt_secret` 通过 AES-GCM 加密后保存到现有 SQLite 设置表，不会返回给前端。

## 恢复

新服务器安装相同版本面板后，在设置页连接同一个 OneDrive，下载云端的
`singbox-panel-backup.tar.gz`，再通过现有的“恢复备份”上传。恢复流程仍会校验归档内容，
并在覆盖前保留回滚副本。

如果 `jwt_secret` 被更换，已保存的 OneDrive 授权无法解密，需要重新连接；数据库备份内容不受影响。
