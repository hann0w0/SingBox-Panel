# 客户端 Logo 资源

本目录存放用户面板订阅目标按钮使用的透明背景 PNG。文件会被 Vite 原样复制到生产资源，
面板通过 `/logos/<文件名>` 访问。

| 客户端 | 文件 | 用途 |
| --- | --- | --- |
| ClashMeta / Mihomo | `clashmeta.png` | Clash/Mihomo 订阅入口 |
| Shadowrocket | `shadowrocket.png` | Shadowrocket 订阅入口 |
| Surge | `surge.png` | Surge 订阅入口 |

这些名称和 Logo 属于各自权利人的商标或品牌资产。本项目仅将它们作为订阅目标的功能性
标识，不表示与相关品牌存在隶属、授权或背书关系。
